# Study-area boundary

No Pokhara polygon is included in this repository because an authorized redistributable boundary file has not been supplied.

The script with unchanged executable logic references the Earth Engine FeatureCollection asset:

`projects/learnpokharalst/assets/boundary/Pokhara`

That path is specific to an Earth Engine project and **may not be accessible to the public**. To reproduce the analysis, obtain a Pokhara boundary from a source you are permitted to use, keep its coordinate system and geometry documented, upload it into your own Earth Engine project, and update the path in your **local execution copy**.

When permission and provenance are established, a public GeoJSON (with attribution and terms) can be included here. Do not publish personal or restricted assets by default.
